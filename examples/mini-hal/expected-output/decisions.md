# 설계 결정 기록

**이 문서는 사람이 씁니다. 코드로 확인할 수 있는 동작은 여기 적지 않고, 코드만 봐서는 알 수 없는 "왜" 를 적습니다.**

항목 하나는 결정 한 가지입니다. 번호는 바꾸지 않고, 뒤집힌 결정은 지우지 않고 "대체됨" 으로 표시합니다. 이유가 기록되지 않은 결정은 이유를 지어내지 않고 "이유 미기록" 으로 남깁니다.

## D-001 (예시 형식)

| 항목 | 내용 |
|---|---|
| 결정 | 무엇을 하기로 했는가 |
| 이유 | 왜 그렇게 했는가. 기록이 없으면 "이유 미기록" |
| 대안 | 검토했지만 택하지 않은 것 |
| 영향 받는 코드 | `파일` 목록 (frontmatter `evidence_files` 에도 적는다) |
| 근거 수준 | 설계 결정 · 검토 회의 날짜 또는 문서 링크 |
| 상태 | 유효 / 대체됨(D-xxx) |

??? note "근거와 검토 정보"
    - 근거 파일: `evidence_files` frontmatter 참조
    - 근거 수준: 설계 결정 (코드 확인 아님)
    - 검토: 아직 검토하지 않았습니다.
