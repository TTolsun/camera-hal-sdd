## 문서를 읽을 때 구분할 것

"코드로 확인한 구조" 아래 문서는 compile DB(NDK-build 구성)를 기준으로 정적 분석한 사실만 담습니다. 기기에서 실행해 본 결과가 아닙니다. "사람이 기록한 설계" 아래 문서는 파이프라인이 덮어쓰지 않으며, 설계 결정과 기기 관찰을 사람이 씁니다.

각 문서 끝의 "근거와 검토 정보"에서 근거 파일, 인용 검증 결과, 검토 상태를 확인할 수 있습니다.

| frontmatter | 뜻 |
|---|---|
| `status: ok` | 본문의 모든 `파일:줄` 인용이 사실 모델에서 확인되었습니다. |
| `status: needs-review` | 인용 검증에 실패했거나, 정적 분석으로는 알 수 없는 절입니다. 내용을 그대로 믿지 마세요. |
| `facts_omitted` | 모델 입력 예산 때문에 제외된 사실입니다. 그 부분은 문서에 없습니다. |
