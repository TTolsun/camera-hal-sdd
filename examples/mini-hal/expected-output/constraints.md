# 변경 시 지켜야 할 제약

**이 문서는 사람이 씁니다. 파이프라인은 덮어쓰지 않고, `evidence_files` 에 적힌 파일이 바뀌면 영향 보고에 "재검토" 로 올립니다.**

아래 항목마다 근거 수준을 적습니다. 코드로 확인한 규칙은 `파일:줄` 을, 설계 결정은 [설계 결정 기록](decisions.md)의 항목 번호를, 기기 관찰은 기기와 날짜를 적습니다. 근거 없는 규칙은 "확인 필요" 로 남깁니다.

## 카메라 점유와 종료 순서

확인 필요: close 완료 전에 다음 open 이 들어오면 어떻게 처리하는지 코드에서 확인하고 규칙을 적습니다.

## 버퍼와 요청의 소유권

확인 필요: 버퍼를 누가 만들고 누가 해제하는지, 프레임워크 콜백 이후 HAL 이 버퍼를 참조하면 안 되는 지점이 어디인지 적습니다.

## Feature flag 조합

확인 필요: 함께 켜면 안 되는 `-D` 조합이 있으면 적습니다. 플래그 목록은 [Feature flag 매트릭스](feature-flags.md)에 있습니다.

## 변경 후 검증

확인 필요: 변경 후 실행해야 하는 테스트 명령과 기기 검증 절차를 적습니다.

??? note "근거와 검토 정보"
    - 근거 파일: `evidence_files` frontmatter 참조
    - 근거 수준: 항목마다 표시
    - 검토: 아직 검토하지 않았습니다.
